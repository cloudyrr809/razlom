# Разломы

Идея и решения — в «Плейс «Разломы» — полное описание (рабочее название).md». Новые решения записывай в его конец.

- Скрипты — только `src/`, Rojo синхронизирует (`rojo serve`, порт 34873). В Studio скрипты не правь.
- Все числа — `src/shared/Config.luau`, формулы — `src/shared/Formulas.luau`. В логике чисел нет.
- Карта строится `tools/build_map.luau` (MCP, execute_luau в Edit: `loadstring(game.ServerScriptService.MapTools.BuildMap.Source)()`), живёт в `Razlom.rbxl`. После правок карты проси сохранить место (Ctrl+S).
- Проверка кода: `.\tools\check.ps1`. Потом — консоль Studio.
- Скиллы — `.Codex/skills`.

## Экономия токенов
- Не читай файлы целиком: Grep → Read с offset/limit. `Razlom.rbxl` и `.md` с описанием не читать без нужды.
- Широкий поиск по коду — через субагента, в контекст только итог.
- Скиллы грузи только по теме задачи; не вызывай несколько сразу.
- Между несвязанными задачами — `/clear`.

## Отчёт после правок кода
Формат строго такой, и ничего сверх него (даже если скилл просит подробный отчёт):
- Одна фраза: что сделано.
- Список изменённых файлов: `путь — что поменял` в одну строку.
- Что не проверено или требует действия (Ctrl+S, перезапуск Rojo), если есть.
Без пересказа диффа, без объяснения причин и без вариантов, пока не спросят.
